
# NUMORA — Number Guessing Game

A simple, interactive number guessing game built with **HTML, CSS, and JavaScript**. Challenge yourself to find the hidden number between 1 and 100 with helpful hints after every guess.

## ✨ Features

- 🎯 Random number generation between 1 and 100
- ⬆️ Hints to help you guess higher or lower
- 📊 Real-time attempt counter
- 🕘 Display of the last guessed number
- ✅ Success message when the correct number is found
- 🔄 Restart button to start a new game
- ⚠️ Input validation with helpful error messages
- 📱 Responsive, mobile-friendly interface
- 🎨 Modern UI with interactive feedback and animations

## 🛠️ Built With

- **HTML5** — Semantic page structure
- **CSS3** — Responsive styling, layout, and animations
- **JavaScript (Vanilla JS)** — Game logic, validation, and DOM manipulation

## 🎮 How to Play

1. Enter a whole number between **1 and 100**.
2. Click **Guess** or press Enter.
3. Read the hint:
   - **Too low:** Try a higher number.
   - **Too high:** Try a lower number.
   - **Correct:** You win!
4. Check your attempt count and last guess.
5. Click **Play Again** to start a new round.
